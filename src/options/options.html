SFCC QA Autofill — Options

Defaults

Emails are generated as prefix-YYYYMMDD-HHMMSSmmm@domain — always unique.

Default mailinator.com: each generated address is a public Mailinator inbox, so you can open the storefront's registration/order emails (the popup links to the inbox after a fill). Anyone can read these inboxes — sandbox data only. Set your own domain here if your team uses a private catch-all instead.

Generated passwords satisfy the SFRA default policy (8+, upper/lower/digit/special).

Per-site selector overrides

JSON keyed by hostname. Each host maps logical field names to selector arrays that are tried before the platform map — use this when a project renamed its fields. Entries are also created by the popup's "Map a field → Pick on page" flow. Shape: {"shop.example.com": {"fields": {"shipping.postalCode": ["#myZip"]}}}

Custom addresses

JSON keyed by ISO country code; records need id, label, address1, city, postalCode (+ state where applicable). They appear first in the popup's address list. Use this for a project-specific address that passed your validator.

Team config

Export/import the whole settings object (defaults, overrides, custom addresses) to share one config across the team.
